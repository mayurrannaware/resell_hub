# ReSell Hub – Managed Second-Hand Marketplace

ReSell Hub is a responsive peer-to-peer web marketplace for buying and selling second-hand goods at fair prices with an integrated escrow and verification system.

## Key Features
- **Escrow & Profit System**: Buyer payments are safely held until inspection; the team automatically retains a 10% platform fee while releasing 90% to the seller.
- **Dynamic Roles**: Dedicated interfaces for Buyers (catalog & search), Sellers (listing & fee preview), and Admins (order approval & profit ledger).
- **Client-Side Storage**: Seamless state persistence using browser `localStorage`.

## Tech Stack
- **Frontend**: Semantic HTML5, CSS3 (Grid & Flexbox), Vanilla JavaScript (ES6+)
- **Tools**: Git, GitHub Pages, VS Code
